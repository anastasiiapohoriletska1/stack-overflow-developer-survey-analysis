# stack-overflow-developer-survey-analysis
Tools: Python, pandas, Jupyter Notebook

Description: Analyzed Stack Overflow developer survey results, exploring patterns in salaries, technology popularity, and work formats to derive analytical insights about the IT job market.

Key Tasks:
Salary analysis of Python developers by country and education level.
Exploring Python popularity across age groups.
Identifying top industries among high-paying remote specialists.
Statistical analysis of respondent experience.

Result: Identified key patterns in salaries and technology demand among developers. Found that 37.5% of respondents use Python, with the highest share among developers aged 18-24 (40%). Showed that fintech is the second most common industry among high-paid remote specialists after software development. Completed a full analysis cycle on a large real-world dataset.
